# Executive Intelligence Architecture

**Owner:** Yemi Odubiyi  
**Status:** Active Build  
**Current Release:** v0.1.0 — Foundation

## Purpose

To preserve institutional memory, strengthen executive judgment, protect attention capital, and improve stewardship through disciplined knowledge, decision intelligence, and continuous learning.

## Core Structure

- `00-Constitution` — enduring principles and governance
- `01-Registers` — decisions, commitments, entities, relationships, and learning
- `02-Entities` — living pages for important people, institutions, themes, and initiatives
- `03-Domains` — segregated fiduciary and operating domains
- `04-Dashboard` — executive cockpit and review pages
- `05-Workflows` — repeatable executive processes
- `06-Templates` — standard reusable records
- `07-Automation` — scripts and automated workflows
- `08-Knowledge` — codified research and reference material
- `09-Projects` — active build and strategic projects
- `99-System` — configuration, administration, releases, and change logs
